Programming assignments for **AIN442 Practicum in Natural Language
Processing**. Each one builds a classic NLP component and reports results
that can be reproduced from the repository.

| Assignment | Topic | Highlights |
|---|---|---|
| PA1 | Byte-Pair Encoding tokenizer | Pure Python; Turkish character support; learns merge rules and encodes unseen text into token IDs |
| PA2 | N-gram language model | Unigram/bigram/trigram counts, add-1 smoothing, perplexity and text generation on a Turkish corpus; standard library only |
| PA3 | Part-of-speech tagging | HMM tagger with Viterbi decoding vs. a feature-based logistic-regression tagger on the Brown corpus |
| PA4 | Word embeddings | word2vec neighbours, sentence vectors and semantic search; IMDB sentiment classifier (averaged word2vec + PyTorch MLP) |
| PA5 | NLI: BERT vs. LLMs | Fine-tuned BERT (90.3% on SNLI test) vs. zero-/few-shot qwen2.5:7b and llama3.2:3b via Ollama, with invalid-output tracking and latency comparison |
